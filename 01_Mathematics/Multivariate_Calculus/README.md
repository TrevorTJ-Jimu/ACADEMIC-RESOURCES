## 📌 Module Overview

**Multivariate Calculus** extends differentiation and integration into **two and three dimensions**, providing the mathematical backbone for physics, engineering simulations, machine learning, and optimisation.

## 📐 Key Formulas

```
Gradient:          ∇f = (∂f/∂x)î + (∂f/∂y)ĵ + (∂f/∂z)k̂

Directional Deriv: D_u f = ∇f · û

Double Integral:   ∬_R f(x,y) dA

Lagrange:          ∇f = λ∇g

Green's Theorem:   ∮_C P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dA
```
