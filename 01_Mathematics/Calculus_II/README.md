## 📌 Module Overview

**Calculus II** extends the tools of Calculus I into **advanced integration techniques**, **sequences and infinite series**, and **introductory differential equations**. It is critical for engineering, physics, and data science students.

## 📐 Key Formulas

```
Integration by Parts:     ∫u dv = uv − ∫v du

Taylor Series:            f(x) = Σ [f⁽ⁿ⁾(a)/n!] · (x−a)ⁿ

Ratio Test:               L = lim|a_{n+1}/a_n|  (converges if L < 1)

Disk Method:              V = π∫[a→b] [f(x)]² dx

Shell Method:             V = 2π∫[a→b] x·f(x) dx
```
