## 📌 Module Overview

**Differential Equations** provides the tools to mathematically describe and solve dynamic systems — processes that change over time or space. Applications span **biomedical systems, electrical circuits, population dynamics, fluid mechanics**, and virtually every area of engineering and science.

## 📐 Key Formulas

```
General First-Order Linear:   dy/dx + P(x)y = Q(x)
Integrating Factor:           μ(x) = e^∫P(x)dx

Characteristic Equation:      ay'' + by' + cy = 0  →  ar² + br + c = 0

Laplace Transform:             L{f(t)} = ∫₀^∞ e^(−st)f(t)dt

L{eᵃᵗ} = 1/(s−a)             L{sin(at)} = a/(s²+a²)

Convolution:                   L{f*g} = F(s)·G(s)
```
