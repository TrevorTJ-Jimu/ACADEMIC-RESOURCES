## 📌 Module Overview

**Introduction to College Algebra and Trigonometry** equips students with the core algebraic and geometric reasoning skills needed for university-level mathematics. Mastery of these fundamentals is essential before progressing to Calculus, Discrete Mathematics, or Statistics.

## 📐 Key Formulas at a Glance

```
Quadratic Formula:     x = (−b ± √(b²−4ac)) / 2a

Pythagorean Identity:  sin²θ + cos²θ = 1

Double Angle:          sin(2θ) = 2·sin(θ)·cos(θ)

Law of Cosines:        c² = a² + b² − 2ab·cos(C)

Log Change of Base:    log_b(x) = ln(x) / ln(b)
```
