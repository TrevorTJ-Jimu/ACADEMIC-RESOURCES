## 📌 Module Overview

**Business Mathematics** applies mathematical tools to real-world financial and commercial problems. Students learn to model business scenarios, analyse financial data, optimise decisions, and apply quantitative reasoning across **finance, economics, and management**.

## 📐 Key Formulas

```
Simple Interest:      I = P·r·t

Compound Interest:    A = P(1 + r/n)^(nt)

Present Value:        PV = FV / (1+r)ⁿ

NPV:                  NPV = Σ [CFₜ/(1+r)ᵗ] − C₀

Break-even:           Q = Fixed Cost / (Price − Variable Cost per unit)

EOQ:                  Q* = √(2DS/H)
```
