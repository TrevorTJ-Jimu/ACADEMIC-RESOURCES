## 📌 Module Overview

**Discrete Mathematics** forms the mathematical foundation of computer science and digital engineering. It covers formal **logic, proof techniques, set theory, graph theory, combinatorics**, and **number theory** — skills essential for algorithm design, cryptography, and software engineering.

## 📐 Key Results

```
De Morgan's Laws:    ¬(P ∧ Q) ≡ ¬P ∨ ¬Q
                     ¬(P ∨ Q) ≡ ¬P ∧ ¬Q

Combinations:        C(n,r) = n! / (r!(n−r)!)

Handshaking Lemma:   Σ deg(v) = 2|E|

Euler's Formula:     V − E + F = 2  (for connected planar graphs)

Fermat's Little:     aᵖ ≡ a (mod p)  for prime p
```
