## 📌 Module Overview

**Physics II** covers **electromagnetism, electric circuits, wave phenomena, and vibrations** — foundational knowledge for electrical engineering, biomedical instrumentation, and communications technology.

## 📐 Key Equations

```
Coulomb's Law:        F = kq₁q₂/r²

Gauss's Law:          ∮E·dA = Q_enc/ε₀

Ohm's Law:            V = IR

Faraday's Law:        EMF = −dΦ/dt

Wave Speed:           v = fλ

SHM Displacement:     x(t) = A·cos(ωt + φ)

Maxwell's Eq. (EM):   c = 1/√(μ₀ε₀) ≈ 3×10⁸ m/s
```
