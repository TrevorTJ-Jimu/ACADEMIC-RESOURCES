## 📌 Module Overview

**Introduction to Statistics and Probability** equips students with the foundational tools to **collect, describe, visualise, and reason about data**. It introduces probability theory as the mathematical framework for quantifying uncertainty — essential for research, decision-making, and all advanced statistics.

## 📐 Key Formulas

```
Mean:               x̄ = Σxᵢ / n

Variance:           s² = Σ(xᵢ − x̄)² / (n−1)

Bayes' Theorem:     P(A|B) = P(B|A)·P(A) / P(B)

Binomial:           P(X=k) = C(n,k)·pᵏ·(1−p)^(n−k)

Normal Z-score:     z = (x − μ) / σ

Poisson:            P(X=k) = (λᵏ·e^−λ) / k!
```
