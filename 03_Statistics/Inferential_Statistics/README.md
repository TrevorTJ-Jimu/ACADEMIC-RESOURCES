## 📌 Module Overview

**Inferential Statistics** goes beyond describing data to **drawing conclusions and testing hypotheses** about populations from sample data. This module is essential for research, clinical trials, policy analysis, and data-driven decision making.

## 📐 Key Formulas

```
Standard Error:        SE = s/√n

Confidence Interval:   x̄ ± z*(s/√n)

t-statistic:           t = (x̄ − μ₀) / (s/√n)

Chi-Square:            χ² = Σ (O − E)² / E

F-statistic:           F = MSB / MSW   (for ANOVA)

Regression Line:       ŷ = β₀ + β₁x

Pearson r:             r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]
```
